# Exchange filing routes supplied by the user

The NSE financial-results page is useful: its original filing index provides disclosure timestamps and links to legacy HTML results or XBRL. The index does not itself contain complete financial statements, and its identifiers still require original-source corroboration.

Following the page's own public JavaScript references, the legacy Alok, Videocon and Can Fin Homes result documents were downloaded through the cached downloader with receipts in `data/raw/nse_results/`. They contain explicit original quarterly, non-cumulative standalone amounts and historical shareholding sections. No JavaScript was executed. These documents are acquisition candidates; they have not been promoted automatically into annual features. Quarter/half-year flows require comparable-period review and a complete disjoint annual/TTM construction before they can supplement annual histories.

Sources: [NSE results](https://www.nseindia.com/companies-listing/corporate-filings-financial-results), [Alok legacy result](https://nsearchives.nseindia.com/archives/financial_results/financial_res_ALOKTEXT_118665.html), [Videocon legacy result](https://nsearchives.nseindia.com/archives/financial_results/financial_res_VIDEOIND_118281.html), [Can Fin Homes legacy result](https://nsearchives.nseindia.com/archives/financial_results/financial_res_CANFINHOME_116586.html).

The BSE announcements URL is a general disclosure route. SEBI's official filing directory separately identifies [BSE shareholding patterns](https://www.bseindia.com/corporates/Sharehold_Searchnew.aspx) and [BSE financial results](https://www.bseindia.com/corporates/Comp_Resultsnew.aspx). The canonical shareholding page's cached HTML is an application shell, not a historical filing export. Browser fetches also returned access errors, so repeated live probing was stopped; cached original filings and the working NSE sources remain available. The official directory is [SEBI corporate filings](https://www.sebi.gov.in/curation/corporate_filings.html).

The target table is `data/manual/shareholding.csv`. Preserve the promoter-denominator definition, reporting period, original dissemination timestamp and source scope. A combined pledged-or-encumbered source tag does not establish a pure-pledge breakdown. Neither an index row nor an empty search supplies a missing financial, pledge or governance value.
